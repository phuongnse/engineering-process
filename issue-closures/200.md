# [consumer-process][engineering-process][2.4.0][pr-evidence-authoring] Reuse canonical lifecycle facts when preparing PR data

## Request

### Context

The engineering-process self-consumer reported that PR evidence authoring could repeat lifecycle facts instead of deriving them from the canonical verified state.

### Expected outcome

Generated PR data reuses the exact canonical source, verification, snapshot, review, finding-disposition, and completion facts from lifecycle evidence while leaving private execution identities in lifecycle state.

## Evidence and scope

### Evidence

The canonical PR-data authoring correction was merged in PR #206 at commit 777392c. The v2.5.0 release recorded the accepted #197-#205 consumer change, and the v2.6.0 adoption PR verified the current self-consumer after adoption.

### Scope

PR description data authoring and its lifecycle evidence boundary; no provider identity inference, no duplicated authority, and no unrelated artifact format change.

### Acceptance criteria

PR data is derived from the verified lifecycle state, stale or mismatched evidence is not presented as current, and the released behavior is adopted and verified by the consumer.
